# MCA Machine Learning — 4th Trimester Labs

Lab assignments for the Machine Learning course in the MCA program (4th trimester). Jupyter notebooks covering core ML concepts from data preprocessing to model building.

## Labs

| Lab | Topic | Key Concepts |
|-----|-------|-------------|
| Lab 1 | Exploratory Data Analysis | Data loading, cleaning, visualization using air quality (`city_day.csv`) and crop production datasets |
| Lab 2 | Linear Regression | Model training, weight serialization (`.pkl`, `.json`), student survey data analysis |
| Lab 4 | Advanced ML Techniques | Model building and evaluation |

## Datasets

- `city_day.csv` — Air quality data across Indian cities
- `crop_production.csv` — Agricultural crop production statistics
- `studentsurvey.xlsx` — Student survey responses for regression analysis

## Tech Stack

- Python
- Jupyter Notebook
- pandas, NumPy, matplotlib, scikit-learn

## Getting Started

```bash
# Install dependencies
pip install jupyter pandas numpy matplotlib scikit-learn openpyxl

# Launch notebooks
jupyter notebook
```
